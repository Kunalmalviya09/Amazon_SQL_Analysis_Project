Amazon E-Commerce SQL Analysis

A 14-question SQL case study on an 11-table e-commerce dataset covering sellers, orders, products, payments and customer reviews. Each question has a query and a short business takeaway.

Tools: MySQL, SQL (JOINs, CTEs, subqueries, window functions, CASE WHEN, HAVING, indexing)

Key Insights
SP, MG and PR lead in order volume; SE, PI and RO have too few orders to justify investment.
Credit card is the most used payment method and has the highest average order value.
Top revenue categories: beleza_saude, relogios_presentes, cama_mesa_banho, esporte_lazer, informatica_acessorios.
Median delivery time is 10 days; November 2017 had the highest order volume.
